ER-диаграмма информационной системы «Учусь.РФ»

users

  • id — PK
  • login — UNIQUE
  • password
  • full_name
  • phone
  • email
  • created_at

courses

  • id — PK
  • name

applications

  • id — PK
  • user_id — FK → users
  • course_id — FK → courses
  • start_date
  • payment_method
  • status
  • created_at

reviews

  • id — PK
  • application_id — FK → applications
  • user_id — FK → users
  • rating
  • text
  • created_at

Связи между сущностями

users (1) — (N) applications — один пользователь может подать несколько заявок

courses (1) — (N) applications — один курс может быть выбран в нескольких заявках

applications (1) — (0..1) reviews — к каждой заявке допускается один отзыв после смены статуса

users (1) — (N) reviews — пользователь может оставить отзывы по своим заявкам
